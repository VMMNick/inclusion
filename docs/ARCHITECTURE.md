# Архітектура

## Принципи

1. **Дані окремо від коду.** Задачки, рівні, машини й сертифікати лежать у `src/data/` як прості об'єкти. Щоб додати контент, не треба розбиратися в логіці.
2. **Кожне завдання — окремий модуль** з однаковим інтерфейсом (`TaskModule`). Застосунок не знає подробиць жодного завдання.
3. **Один реєстр** (`src/tasks/registry.js`) визначає, які завдання є і в якому порядку.
4. **Модулі спілкуються через події** (`src/core/events.js`), а не через прямі виклики. Наприклад, завдання повідомляє «я виконане», а кнопка «Далі», панель кроків і банер сертифіката реагують на це самі.
5. **Чиста логіка винесена з інтерфейсу**: рух робота, перевірка сортування, навігація, розбір відповіді Вікіпедії. Її покривають прості тести.
6. **Без фреймворку.** Використано звичайний JavaScript (ES-модулі), Tailwind для стилів і Vite для збірки. Код легко читати, а результат — один легкий файл.

## Життєвий цикл

```
main.js → createApp(TASKS)
  ├─ createWelcome()                       екран вибору
  ├─ для кожного task з реєстру:
  │    createTaskSection(task)             каркас розділу
  │    mountCertificateBanner(slot, task)  банер «Ти отримуєш сертифікат…»
  │    task.mount({ section, body, nextButton, complete })
  ├─ createFinalAward()                    нагорода
  ├─ createRouter(pages)                   навігація
  └─ mountCertificateModal()               вікно сертифіката
```

## Інтерфейс завдання (`TaskModule`)

```js
export default {
  key: 'robot',                   // унікальний ключ
  icon: '🤖', title: '…', label: '…', desc: '…', theme: 'teal',
  intro: 'Інструкція під заголовком',
  skill: 'програмує робота',      // або () => '…' (для сертифіката: «за те, що …»)
  template,                       // HTML тіла (з файлу .html?raw)
  actions: '<button…>',           // необов'язково: кнопки поруч із «Далі»
  mount({ section, body, nextButton, complete }) { … },  // один раз
  reset() { … },                  // «Пройти ще раз»
  onEnter() { … },                // необов'язково: коли відкрили розділ
  awardNote: () => '…'            // необов'язково: рядок на нагороді
};
```

Коли учень розв'язав завдання, модуль викликає `complete()`. Решта відбувається автоматично:
- вмикається кнопка «Далі»;
- з'являється банер сертифіката;
- на панелі кроків з'являється ✓;
- завдання потрапляє в підсумкову нагороду.

## Події

| Подія | Коли | Хто слухає |
|---|---|---|
| `task:completed` | завдання виконано | кнопка «Далі», банер, панель кроків |
| `session:reset` | «Пройти ще раз» | те саме |
| `selection:changed` | змінено вибір завдань | вітання, панель кроків |
| `name:changed` | змінено ім'я | вікно сертифіката, нагорода |
| `page:changed` | відкрито інший екран | (вільна для аналітики/розширень) |

## Рецепти

**Нова вікторина** (наприклад, «Рослини»):
1. Скопіюй `src/data/quizzes/space.js` у `plants.js`, зміни `key`, тексти й задачки.
2. Додай `import plants from './plants.js'` у `src/data/quizzes/index.js` і впиши `plants` у `THEME_QUIZZES`.
3. За бажанням додай `plants: { title: 'Юний ботанік', decor: ['🌱','🌻','🌳','🍀'] }` у `certificates.js`.
4. Запусти `npm test`.

**Нове завдання зі своєю механікою** (наприклад, «Пазл»):
1. Створи `src/features/puzzle/puzzle.js` (+ `puzzle.html`) за зразком `robot/`.
2. Логіку без DOM винеси в окремий файл і напиши для неї тест.
3. Додай модуль у `src/tasks/registry.js`.

**Новий колір теми:** додай кольори в `tailwind.config.js` → `theme.extend.colors`, а запис — у `src/config/themes.js`. Класи пиши повними рядками.

## Тести

- `tests/data.test.js` перевіряє цілісність усіх даних:
  - у кожній задачці правильна відповідь є серед варіантів;
  - кожен рівень робота можна пройти (пошук найкоротшого шляху);
  - теми й ключі існують.
- `tests/logic.test.js` перевіряє чисту логіку: навігацію, робота, сортування, алгоритм і фото.
- `tests/app.test.js` — наскрізний сценарій: вибір → проходження → сертифікат з іменем → нагорода → «Пройти ще раз».

## Доступність (чекліст для нових завдань)

- [ ] Усі дії доступні з клавіатури (кнопки — це `<button>`).
- [ ] Емодзі-картинки мають `aria-hidden="true"`, зміст передано текстом.
- [ ] Повідомлення виводяться в контейнер з `role="status" aria-live="polite"`.
- [ ] Немає таймерів, автопереходів і червоних «помилок»: лише `needs-review` і жовті підказки.
- [ ] Анімації враховують `prefersReducedMotion()`.
- [ ] Після дії фокус переходить на логічне місце (`focusQuietly`).
