# 🧪 Лабораторія логіки та сортування

Навчальний вебдодаток з логіки та інформатики для учнів **3–5 класів**. Він створений з особливою увагою до дітей з розладами аутистичного спектра (РАС) і з різним рівнем навичок читання та моторики.

Увесь застосунок — це **один файл `index.html`**. Збирати чи встановлювати нічого не потрібно.

## Що всередині

**18 категорій.** Учень сам обирає, які з них проходити:

| | Категорія | | Категорія |
|---|---|---|---|
| 🗂️ | Розклади картки (3 рівні: 2–4 коробки) | 🛡️ | Безпека в інтернеті |
| 🪜 | Склади алгоритм (3 теми) | ⌨️ | Чарівна клавіатура |
| 🔎 | Знайди зайве | 🔢 | Математична логіка |
| 🔁 | Що буде далі? | 🐾 | Світ тварин |
| 🤔 | Правда чи ні? | 🗓️ | Пори року і час |
| 🤖 | Робот-помічник (програмування стрілками) | 💙 | Моя Україна |
| 🚗 | Машини та марки (реальні фото) | 🎨 | Кольори та фігури |
| 🚀 | Космічна подорож | 👷 | Професії |
| 🚦 | Безпечна дорога | 🎵 | Музична скринька |

**Нагороди:**
- кожна категорія має власний тематичний сертифікат, який можна надрукувати;
- у фіналі учень отримує загальну нагороду «Магістр Логіки».

## Принципи доступності

- **Без таймерів і покарань.** Помилка дає лише м'яку жовту підказку, а повернутися назад можна будь-коли.
- **Передбачуваність.** Немає автоматичних переходів: наступна задачка відкривається тільки кнопкою.
- **Звук вимкнено за замовчуванням.** Якщо його увімкнути, лунають м'які дзвіночки, синтезовані через Web Audio API.
- **Пастельна палітра.** У ній немає різкого червоного.
- **Кілька способів керування.** Працюють і перетягування, і «клікни картку → клікни коробку», а також клавіатура (Tab, Enter, Esc).
- **Підтримка налаштувань системи.** Застосунок враховує `prefers-reduced-motion`, має видимий фокус і підписи для екранних читачів.

## Запуск

**Локально:** просто відкрий `index.html` у браузері (Chrome, Edge, Firefox, Safari).

**Як сайт на GitHub Pages:**
1. Запуш репозиторій на GitHub.
2. Відкрий **Settings → Pages → Deploy from a branch**, обери гілку `main` і папку `/ (root)`.
3. Сайт з'явиться за адресою `https://<логін>.github.io/<репозиторій>/`.

> Для роботи потрібен інтернет: стилі (Tailwind CDN), шрифт Nunito і фото машин із Вікіпедії підвантажуються з мережі. Без інтернету замість фото з'явиться заглушка 🚗.

## Як додати свій контент

Усі дані лежать на початку скрипта в `index.html`:

| Що додати | Де |
|---|---|
| Нову категорію-вікторину | масив `EXTRA_TASKS` (розділ, картка у виборі й сертифікат з'являться автоматично) |
| Звання й орнамент сертифіката | об'єкт `CERTS` |
| Задачки «Зайве», «Що далі?», «Правда чи ні?» | `QUIZZES.odd`, `QUIZZES.pattern`, `QUIZZES.truth` |
| Категорії та картки сортування | `SORTING_LEVELS` |
| Теми алгоритмів | `ALGO_TOPICS` |
| Рівні робота | `ROBOT_LEVELS` |
| Машини (можна з власним фото через поле `photo`) | `CARS` |
