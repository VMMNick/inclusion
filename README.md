# 🧪 Лабораторія логіки та сортування

Навчальний вебдодаток з логіки та інформатики для учнів **3–5 класів**. Він створений з особливою увагою до дітей з розладами аутистичного спектра (РАС) і з різним рівнем навичок читання та моторики.

- **18 категорій.** Учень сам обирає, які з них проходити.
- **Тематичні сертифікати.** Кожна категорія має свій сертифікат із полем «Кому видається»: ім'я можна вписати на екрані або залишити лінію для ручки.
- **Підсумкова нагорода «Магістр Логіки».**
- **Без таймерів і покарань.** Звук вимкнено за замовчуванням, кольори пастельні.
- **Повне керування з клавіатури.** Враховано налаштування `prefers-reduced-motion`.

## Швидкий старт

```bash
npm install
npm run dev        # режим розробки з автооновленням → http://localhost:5173
npm test           # тести (дані, логіка, наскрізний сценарій)
npm run build      # збірка в один файл dist/index.html
npm run preview    # перегляд зібраної версії
```

Потрібен Node.js 18 або новіший.

Збірка дає **один самодостатній файл** `dist/index.html`, у який уже вбудовано стилі, скрипти й шрифт. Його можна:
- викласти на GitHub Pages (автоматично, див. нижче);
- просто відкрити в браузері з флешки, без інтернету. Без мережі не покажуться лише фото машин: замість них з'явиться заглушка 🚗.

## Публікація на GitHub Pages

У репозиторії вже є workflow `.github/workflows/deploy.yml`. Його треба один раз увімкнути:

1. Відкрий **Settings → Pages → Build and deployment → Source** і обери **GitHub Actions**.
2. Зроби `git push` у гілку `main`.

Далі після кожного пушу запускаються тести, потім збірка, потім публікація. Якщо тести падають, сайт не оновлюється, і зламана версія не потрапить до учнів.

## Як додати контент

| Що зробити | Де |
|---|---|
| Нова категорія-вікторина | новий файл у `src/data/quizzes/` + рядок у `src/data/quizzes/index.js` |
| Звання й орнамент сертифіката | `src/data/certificates.js` |
| Задачки в наявній вікторині | відповідний файл у `src/data/quizzes/` |
| Коробки й картки сортування | `src/data/sorting-levels.js` |
| Теми алгоритмів | `src/data/algorithm-topics.js` |
| Рівні робота | `src/data/robot-levels.js` |
| Машини (і власні фото у `public/photos/`) | `src/data/cars.js` |
| Нове завдання з власною механікою | папка в `src/features/` + рядок у `src/tasks/registry.js` |

Після змін запусти `npm test`. Тести перевірять, що в кожній задачці правильна відповідь є серед варіантів, кожен рівень робота можна пройти, усі теми існують тощо.

Детальніше про будову проєкту: **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**.
